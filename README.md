# 🐺 EcoLifeSim

**EcoLifeSim** is an ecological simulation system inspired by **Conway's Game of Life**, creatively modeling a simple food chain where **wolves eat sheep**, and **sheep eat grass**.

## 🌱 Overview

This project simulates population dynamics and ecosystem balance through adjustable parameters and survival rules. Users can explore how different rule sets affect species coexistence and stability in a simplified food web.

## 🔧 Features

- Rule-based simulation inspired by cellular automata
- Three-species ecosystem: grass → sheep → wolf
- Adjustable parameters (e.g., reproduction rate, hunger limit, lifespan)
- Visualization of population changes over time
- Educational tool for understanding ecosystem interactions

## 🎯 Goal

To provide an interactive way to explore **ecological balance**, **predator-prey dynamics**, and the **impact of environmental rules** using simple, game-inspired logic.
